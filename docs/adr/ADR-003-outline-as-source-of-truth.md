# ADR-003 — Outline como fuente de verdad documental

## Estado
Aceptado

## Decisión
Todo plan operativo, decisión técnica relevante, incidente y reporte post-trade debe registrarse en Outline.

## Justificación
Se busca trazabilidad completa entre hipótesis, señal, riesgo, ejecución y resultado.

## Consecuencias
- El bot debe poder publicar documentos en Outline automáticamente.
- El frontend debe enlazar documentos y evidencias.
- Un trade sin documentación es un trade incompleto.
