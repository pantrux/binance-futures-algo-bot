# Fase: persistencia + Binance Testnet + trade plans

## Entregables
- Modelo persistente `trade_plans`
- Base SQLAlchemy + Alembic
- Endpoint `POST /trade-plans`
- Endpoint `GET /integrations/binance/testnet/ping`
- Servicio de persistencia + publicación opcional en Outline

## Objetivo
Pasar de una fundación conceptual a una plataforma que ya pueda registrar planes operativos auditables y verificar conectividad con Binance Futures Testnet.

## Restricciones
- Sin live trading.
- Todo sigue orientado a Synology como runtime final.
- Todo cambio debe reflejarse en Outline.
